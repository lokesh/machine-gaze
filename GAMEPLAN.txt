MACHINE GAZE - DEVELOPMENT GAMEPLAN
=====================================

PROJECT OVERVIEW
-----------------
Research/art project for computer vision analysis of pre-recorded video clips (15-30 seconds typically).
Goal: Create extensible system for object detection + emotion analysis with annotated video output.
Processing: Offline batch processing (overnight for hours of footage acceptable).
Platform: Local M1 Mac, no real-time constraints.

IMPLEMENTATION PLAN
-------------------

PHASE 1: CORE ARCHITECTURE ⭐ (START HERE)
------------------------------------------
□ Set up modular project structure with extensible classifier framework
□ Implement YOLO-World as primary object detector (easiest for local setup)
□ Create basic video I/O and overlay rendering system
□ Build ClassifierRegistry pattern for easy extension

Target Objects (Initial):

TECHNICAL DECISIONS
-------------------

Primary Detector: YOLO-World
- Rationale: Ultralytics ecosystem, mature documentation, excellent local setup
- Good speed/accuracy balance for offline processing
- Easy extension with custom classes

Architecture: Modular ClassifierRegistry
- Easy to add new classifiers (gesture recognition, activity detection, etc.)
- Configuration-driven (thresholds, enabled classifiers, styling)
- Clean separation between detection, tracking, and rendering

Output: Annotated video files with overlays
- Bounding boxes with labels and confidence scores
- Emotion labels on detected faces
- Track IDs and motion trails
- Configurable styling (colors, fonts, etc.)
